# End-of-pilot survey (pilot analyst + security owner)

Sent at pilot end. Answers are quoted only with permission; numbers are
aggregated per `pilot-metrics.md`. This form collects no traffic data.

## A. Accuracy (your labels, your words)

1. Over the pilot, how many findings did you label? confirmed _ / false
   positive _ / accepted risk _ (or "did not label — why:")
2. Which rule produced the most noise? Was it suppressible with the
   scoping you needed? (rule id + yes/no)
3. Describe one finding you trusted, and one you did not — what made the
   difference?
4. Did you detect anything you would otherwise have missed? (yes/no +
   optional detail)
5. Did anything the tool reported contradict what you knew to be true?
   (this is the false-positive signal — describe)

## B. Install and operation

6. How long did the install actually take, vs the one-hour target? Where
   did it go over?
7. Which pre-flight or doctor check was most/least useful?
8. Anything you had to work around? (docs, defaults, missing checks)
9. Did the disk/rotation/backup defaults fit your environment?

## C. Usefulness

10. Which report or dashboard view did you actually use weekly? Which did
    you never open?
11. Were remediation steps attached to findings actionable? (cite a rule
    where they were / were not)
12. What decision did CipherPost help you make (if any)?

## D. Performance and fit

13. Resource impact acceptable? (CPU/RAM/disk, any throttling you did)
14. Capture placement: did you get the coverage you expected? (see
    `docs/live-run/capture-placement.md` checklist result)

## E. Going forward

15. Willingness to continue (as-is / with changes / no) — why?
16. The single change that would most increase the value of a next phase?
17. May we quote your answers (with attribution / anonymously / not at
    all)? ______
